# Incident-IQ Learning Guide

Welcome to the **Incident-IQ Learning Guide**. This repository acts as a comprehensive, step-by-step educational resource for understanding the `Incident-IQ` (RCA_Hackthon) project. 

Whether you are a new developer onboarding onto the project or someone looking to understand its architecture, this folder contains everything you need to know about how the application connects its React frontend to its LangChain + FastAPI backend.

## How to Read This Guide
Start with `PROJECT_MAP.md` and `ARCHITECTURE.md` to get a bird's-eye view. Then explore specific modules like `RAG.md` or `PGVECTOR.md` based on your interests.
