# Requirements & Dependencies

## Backend (`requirements.txt`)
- **FastAPI / Uvicorn**: The web framework and ASGI server.
- **Psycopg / pgvector**: PostgreSQL connection and vector operations.
- **Langchain / google-genai**: AI orchestration and LLM integration.
- **Sentence-transformers**: Local embedding generation.
- **PyMongo**: MongoDB integration.
- **PyPDF / Pandas / Numpy**: Data processing and loading.

## Frontend (`package.json`)
- **React / Vite**: UI library and build tool.
- **Zustand**: Lightweight global state management.
- **TanStack Query**: Data fetching and caching.
- **React Hook Form / Zod**: Form management and validation.
- **ECharts**: Data visualization.
